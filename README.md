# Исследование эффективности ИИ в разработке инди-игр без ручного кодинга

## Название проекта
Исследование эффективности современных моделей ИИ в разработке инди-игр без написания кода вручную.

- **Андрей Гузырь** — Тестировщик / UX-дизайнер
- **Куратор:** Голик Антон Юрьевич

## Цель
Оценить и сравнить возможности классических нейросетей и специализированных AI-платформ в создании браузерной игры «Змейка» без ручного вмешательства в код, создав итоговый гид-рейтинг для пользователей.

## Гипотеза
Если использовать специализированные ИИ-платформы (Qwen, Bolt.new), то процесс разработки будет более автономным, а финальный визуальный стиль и стабильность кода окажутся выше, чем у классических текстовых чатов (ChatGPT, Claude, DeepSeek).

## Платформа
- HTML5 + CSS3 + JavaScript (vanilla).
- Каждая версия игры — один файл `index.html`.
- Игра должна работать в браузере на компьютере и на телефоне.
- Управление: стрелки на клавиатуре + свайпы + экранные кнопки на мобильных.
- Хостинг: GitHub Pages.

## Как работать с проектом
1. Прочитай `docs/technical-specification.md` — там полное ТЗ.
2. Используй промпты из `prompts/` для каждой нейросети.
3. Сохраняй полученный код в `ai-versions/<нейросеть>/index.html`.
4. Открывай файл в браузере или запусти локальный сервер: `python -m http.server 8000`.
5. Проверяй на телефоне: открой по IP компьютера в той же Wi-Fi-сети.
6. Фиксируй баги в `data/bug-log.md`.
7. Заполняй оценки в `data/score-table.md`.
8. После завершения всех тестов собери финальный хаб в `hub/`.
