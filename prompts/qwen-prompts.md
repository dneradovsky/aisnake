# Промпты для Qwen

## Базовый промпт
```
Создай браузерную игру «Змейка» в виде одного HTML-файла. Игра должна работать и на компьютере, и на телефоне.

Требования:
1. HTML5 + CSS3 + JavaScript (vanilla), один файл index.html.
2. Корректный viewport для мобильных: width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no.
3. Игровое поле квадратное, минимум 400×400 px на десктопе, на телефоне адаптируется под ширину экрана (минимум 300×300 px).
4. Змейка начинает движение из центра, длина — 3 сегмента.
5. Управление:
   - На компьютере: стрелки клавиатуры (↑ ↓ ← →).
   - На телефоне: свайпы вверх/вниз/влево/вправо + экранные кнопки-стрелки минимум 60×60 px.
   - Запрет разворота на 180°.
6. Еда появляется в случайной клетке, не на теле змейки.
7. При поедании еды змейка растёт на 1 сегмент, счёт увеличивается на 1.
8. Столкновение со стенкой или с собственным хвостом — проигрыш.
9. После проигрыша выводится сообщение и кнопка рестарта (на ПК также Space/Enter, на телефоне — тап по экрану).
10. Счёт отображается на экране.
11. Страница не должна скроллиться или зумиться при свайпах (touch-action: none, preventDefault).
12. Код должен быть чистым, с комментариями на русском языке.

Дай полный рабочий код. Проверь, чтобы не было ошибок в консоли браузера.
```

## Промпт второго этапа
```
Добавь в игру «Змейка» следующие функции. Сохрани работу на телефонах.

1. Два уровня сложности: Лёгкий (медленная скорость, без стен) и Сложный (быстрая скорость, стены убивают, ускорение). Переключатель в интерфейсе.
2. Анимация поедания еды (мигание, частицы или увеличение).
3. Звуки: поедание еды и проигрыш. Используй Web Audio API или base64. Кнопка вкл/выкл звука.
4. Сохранение лучшего результата (high score) и выбранного уровня сложности в LocalStorage.
5. Плавное движение змейки.
6. Убедись, что управление на телефоне (свайпы и экранные кнопки) остаётся удобным.

Исправь все баги, которые могут возникнуть при добавлении новых функций. Верни полный обновлённый код index.html.
```

## Промпт для дебаггинга
```
В моей версии игры «Змейка» обнаружена ошибка.

Описание проблемы: [опиши баг]
Устройство: [десктоп / телефон / браузер]
Лог ошибки из консоли: [вставь лог]

Исправь код и верни полный обновлённый index.html. Объясни, в чём была причина ошибки.
```

## Советы по работе с Qwen
- Qwen хорошо справляется с длинным кодом, но может давать объяснения до кода — попроси «сначала код, потом пояснения».
- Уточняй, что нужен полный файл index.html, а не фрагменты.
- Если возникают проблемы с мобильной версией, приложи скриншот и укажи модель телефона.
- Проверяй мобильную версию через DevTools (Ctrl+Shift+M) или на реальном телефоне.
