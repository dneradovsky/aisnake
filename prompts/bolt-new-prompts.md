# Промпты для Bolt.new

## Подготовка
1. Открой https://bolt.new в браузере.
2. Создай новый проект.
3. Убедись, что проект настроен как статический сайт (HTML/CSS/JS).

## Базовый промпт
```
Создай браузерную игру «Змейка» на HTML/CSS/JavaScript. Игра должна работать на компьютере и на телефоне.

Требования:
1. Всё в одном HTML-файле.
2. Viewport для мобильных: width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no.
3. Игровое поле 400×400 px на десктопе, на телефоне адаптируется (минимум 300×300 px).
4. Змейка длиной 3 сегмента, стартует в центре.
5. Управление:
   - Компьютер: стрелки клавиатуры.
   - Телефон: свайпы + экранные кнопки-стрелки (минимум 60×60 px).
   - Запрет разворота на 180°.
6. Еда в случайной свободной клетке.
7. Змейка растёт при поедании, счёт +1.
8. Проигрыш при столкновении со стеной или собственным хвостом.
9. Экран Game Over и кнопка рестарта.
10. Счёт отображается.
11. Страница не скроллится и не зумится при свайпах.
12. Чистый код с комментариями на русском.

Сделай так, чтобы игра сразу запускалась в preview.
```

## Промпт второго этапа
```
Добавь в игру «Змейка»:

1. Два уровня сложности: Лёгкий (медленно, сквозь стены) и Сложный (быстро, стены убивают, ускорение). Переключатель в интерфейсе.
2. Анимация поедания еды (частицы/мигание).
3. Звуки: поедание, проигрыш, кнопка M — вкл/выкл звук. Используй Web Audio API или base64.
4. LocalStorage для сохранения лучшего счёта и выбранного уровня сложности.
5. Плавная графика.
6. Проверь, что на телефоне игра помещается на экран без прокрутки.

Исправь все баги, которые могут появиться. Покажи обновлённую версию.
```

## Промпт для дебаггинга
```
В игре «Змейка» баг.

Описание: [опиши проблему]
Устройство: [десктоп / телефон]
Ошибка в консоли: [вставь лог]

Исправь и обнови проект. Кратко объясни причину.
```

## Советы по работе с Bolt.new
- Bolt.new сам создаёт файлы и структуру проекта — проверяй, что в итоге получилось.
- Используй preview для быстрого тестирования.
- Если нужен один файл для GitHub Pages, попроси: «Объедини всё в один index.html».
- Bolt.new может создавать лишние файлы — удаляй ненужные перед публикацией.
