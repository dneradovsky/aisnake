# Промпты для DeepSeek

## Базовый промпт
```
Напиши браузерную игру «Змейка» на HTML/CSS/JavaScript в одном файле index.html. Игра должна работать на компьютере и телефоне.

Требования:
1. Один файл index.html.
2. Viewport для мобильных: width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no.
3. Окно 400×400 px на десктопе, на телефоне адаптируется (минимум 300×300 px).
4. Змейка длиной 3 сегмента, стартует в центре.
5. Управление:
   - Компьютер: стрелки.
   - Телефон: свайпы + экранные кнопки (минимум 60×60 px).
   - Запрет разворота на 180°.
6. Еда в случайной клетке, не на змейке.
7. Змейка растёт при поедании, счёт увеличивается.
8. Столкновение со стеной или хвостом — проигрыш.
9. После проигрыша — сообщение и кнопка рестарта.
10. Счёт отображается.
11. Страница не скроллится при свайпах.
12. Код простой, рабочий, с русскими комментариями.

Верни полный HTML-код, который можно сохранить и сразу открыть в браузере.
```

## Промпт второго этапа
```
Доработай игру «Змейка»:

1. Добавь два режима сложности: Лёгкий (медленно, проход сквозь стены) и Сложный (быстро, стены убивают, ускорение).
2. Добавь анимацию при поедании еды.
3. Добавь звуки через Web Audio API или base64. Клавиша/кнопка M — вкл/выкл звук.
4. Сохраняй лучший счёт и выбранный режим в LocalStorage.
5. Сделай рестарт корректным при смене сложности.
6. Проверь, что управление на телефоне не ломается.

Верни полный index.html.
```

## Промпт для дебаггинга
```
В игре «Змейка» ошибка.

Что сломано: [описание]
Устройство: [десктоп / телефон]
Текст ошибки из консоли: [лог]

Исправь и пришли полный обновлённый index.html. Объясни вкратце, в чём была ошибка.
```

## Советы по работе с DeepSeek
- DeepSeek часто даёт короткие ответы — уточняй, что нужен полный файл.
- Может потребоваться больше итераций дебаггинга.
- Для сложных задач разбивай запрос: сначала базовая игра, потом улучшения.
- Проверяй код вручную после каждой генерации, особенно тач-события.
