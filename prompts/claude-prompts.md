# Промпты для Claude

## Базовый промпт
```
Напиши полноценную браузерную игру «Змейка» в одном HTML-файле. Игра должна работать на компьютере и на мобильных устройствах.

Требования:
1. HTML5, CSS3, vanilla JavaScript. Всё в одном файле index.html.
2. Viewport для мобильных: width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no.
3. Игровое поле 400×400 px на десктопе, адаптируется на телефоне (минимум 300×300 px).
4. Змейка стартует в центре, длина — 3 сегмента.
5. Управление:
   - Десктоп: стрелки клавиатуры.
   - Телефон: свайпы + экранные кнопки-стрелки (минимум 60×60 px).
   - Запрет разворота на 180°.
6. Еда в случайной свободной клетке.
7. Рост змейки и счёт +1 за каждую еду.
8. Проигрыш при столкновении со стеной или собственным хвостом.
9. Экран Game Over с кнопкой рестарта (Space/Enter на ПК, тап на телефоне).
10. Счёт виден на экране.
11. Предотвращение скролла/зума страницы при свайпах.
12. Код должен быть аккуратно структурирован и прокомментирован по-русски.

Верни готовый к запуску код.
```

## Промпт второго этапа
```
Улучши игру «Змейка». Сохрани мобильную поддержку.

1. Добавь выбор уровня сложности перед игрой:
   - Easy: медленная скорость, змейка проходит сквозь стены.
   - Hard: высокая скорость, стены смертельны, скорость немного увеличивается с ростом счёта.
2. Добавь анимацию: плавное движение, визуальный эффект при поедании еды.
3. Добавь звуки (Web Audio API или base64): звук еды, звук проигрыша, кнопка mute/unmute.
4. Используй LocalStorage для сохранения high score и последнего выбранного уровня сложности.
5. Убедись, что на телефоне управление остаётся удобным после добавления новых UI-элементов.

Верни полный обновлённый код index.html.
```

## Промпт для дебаггинга
```
В сгенерированной тобой игре «Змейка» есть баг.

Проблема: [описание]
Устройство: [десктоп / телефон]
Лог из DevTools Console: [лог]

Проанализируй причину, исправь код и пришли полный обновлённый index.html. Кратко объясни, что было сломано.
```

## Советы по работе с Claude
- Claude хорошо пишет длинный код сразу целиком.
- Можно прикреплять текущий код и просить доработать именно его.
- Используй Claude 3.5 Sonnet или Claude 3 Opus.
- Если Claude даёт много объяснений, попроси: «Сначала дай код, потом кратко поясни».
