# Паспорт проекта 2026

## Название
Исследование эффективности современных моделей ИИ в разработке инди-игр без написания кода вручную.

## Необходимые консультанты
- **Голик Антон Юрьевич** (учитель информатики) — проконсультирует по правильности кода игры на p5.js и поможет разобраться в логах ошибок, если нейросети начнут выдавать неработающий бред.
- **Знакомые программисты** — помогут оценить качество кода со стороны профессионалов, чтобы оценка была максимально объективной.

## Актуальность
Проект необходим для начинающих разработчиков, геймдизайнеров и обычных людей, которые хотят создавать свои цифровые продукты, но не имеют навыков программирования. В 2026 году технологии «вайб-кодинга» (разработки игр через общение с ИИ) стали массовыми, и обществу нужен чёткий путеводитель по возможностям нейросетей, чтобы понимать, какие из них реально работают, а какие допускают критические ошибки.

## Проблема
Высокий порог входа в программирование мешает людям реализовывать свои идеи игр, при этом существующие заявления о том, что «ИИ может полностью написать игру за человека», остаются субъективными и не проверенными на практике по строгим критериям.

## Цель
Оценить и сравнить возможности классических нейросетей и специализированных AI-платформ разработки в создании браузерной игры «Змейка» без ручного вмешательства в код, создав итоговый гид-рейтинг для пользователей.

## Задачи и сроки
1. Разработать подробное техническое задание (ТЗ) для игры «Змейка» с двумя уровнями сложности. (1 неделя)
2. Настроить рабочее окружение, распределить роли в команде и получить доступы к ИИ (ChatGPT, Claude, DeepSeek, Qwen, Bolt.new). (1 неделя)
3. Провести первый этап тестирования (базовый уровень) и зафиксировать, как ИИ справляется с созданием игры. (2 неделя)
4. Провести второй этап тестирования (добавление анимации, звуков и LocalStorage) и проверить навыки автономного дебаггинга (поиска и исправления ошибок в коде) ИИ. (3 неделя)
5. Собрать статистику багов и промптов, сформировать сводную таблицу оценок от 1 до 10. (4 неделя)
6. Развернуть получившиеся игры на хостинге (GitHub Pages), создать QR-коды для презентации и оформить финальный гид по выбору ИИ. (5 неделя)

## Гипотеза
Если использовать для создания игры специализированные ИИ-платформы, то процесс разработки будет более автономным, а финальный визуальный стиль и стабильность кода окажутся значительно выше, чем при использовании классических текстовых чатов (ChatGPT).

## Ресурсы
- Компьютеры/смартфоны с доступом в интернет.
- Аккаунты на платформах ИИ: OpenAI (ChatGPT), Anthropic (Claude), DeepSeek, Qwen IDE, Bolt.new.
- Бесплатный хостинг для публикации игр (GitHub Pages).
- Программное обеспечение для создания презентации и вывода QR-кодов.

## Продукт
Интерактивный веб-хаб с 5 работающими версиями игры «Змейка», полностью написанными разными нейросетями, и «гид по выбору ИИ 2026» со сводной таблицей оценок, доступный для тестирования комиссии через QR-коды на презентации.
